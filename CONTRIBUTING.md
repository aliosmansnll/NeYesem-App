# Katkıda Bulunma Rehberi

NeYesem projesine katkıda bulunmak istediğiniz için teşekkür ederiz! 🎉

## Katkı Süreci

1. **Fork & Clone**
   ```bash
   git clone https://github.com/YOUR-USERNAME/neyesem.git
   cd neyesem
   ```

2. **Branch Oluşturun**
   ```bash
   git checkout -b feature/yeni-ozellik
   ```

3. **Geliştirme Yapın**
   - Kod standartlarına uyun
   - Yorumlar ekleyin
   - Test edin

4. **Commit**
   ```bash
   git add .
   git commit -m "feat: yeni özellik eklendi"
   ```

5. **Push & Pull Request**
   ```bash
   git push origin feature/yeni-ozellik
   ```
   GitHub'da Pull Request oluşturun

## Kod Standartları

### Python (Backend)
- PEP 8 standartlarına uyun
- Type hints kullanın
- Docstring'ler ekleyin

### JavaScript (Frontend)
- ESLint kurallarına uyun
- Anlamlı değişken isimleri kullanın
- Component'leri küçük ve yeniden kullanılabilir tutun

## Commit Mesajları

Conventional Commits formatını kullanın:
- `feat:` - Yeni özellik
- `fix:` - Hata düzeltme
- `docs:` - Dokümantasyon
- `style:` - Kod formatı
- `refactor:` - Kod yeniden yapılandırma
- `test:` - Test ekleme
- `chore:` - Bakım işleri
